# ระบบแผนที่น้ำท่วม บางระกำ หมู่ 15 (Flood GIS)

เว็บแอปพลิเคชันระบบสารสนเทศภูมิศาสตร์ (GIS) สำหรับติดตามและวิเคราะห์ความถี่น้ำท่วม บางระกำ หมู่ 15

## วิธีการรันโปรเจกต์ด้วย Node.js

1. ติดตั้ง dependencies:
   ```bash
   npm install
   ```

2. เริ่มต้นรันเซิร์ฟเวอร์:
   ```bash
   npm start
   ```

3. เปิดเบราว์เซอร์ที่:
   [http://localhost:3000](http://localhost:3000)
